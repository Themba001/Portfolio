# Themba Mabuza - Personal Portfolio Website

This is the official portfolio website of Themba Mabuza, a BSc Information Technology student majoring in Software Development at North-West University (Vaal Campus), South Africa. The website showcases academic projects, technical skills, resume information, and contact details in a modern, animated interface.

## Purpose

The goal of this portfolio is to demonstrate technical proficiency, personal branding, and professionalism in preparation for internship and job opportunities—particularly with companies such as Amazon (Cape Town), as well as showcasing past work like the Emergency App for off-campus students.

## Features

- Fully responsive and mobile-friendly
- Smooth animations and transitions
- Cosmic-themed landing page with animated backgrounds
- Project showcase with interactive cards and detail expansion
- Integrated resume and skill set sections
- Contact form for direct communication
- Footer with external profile links (GitHub, LinkedIn, etc.)

## Technologies Used

- HTML5
- Tailwind CSS v3.4.1
- JavaScript (Vanilla)
- FontAwesome (for icons)
- VS Code Live Server (for local testing)

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Themba001/portfolio.git
   cd portfolio

2. Install Tailwind dependencies:
    npm install -D tailwindcss@3.4.1

3. Start Tailwind build process:
    npx tailwindcss -i ./css/tailwind.css -o ./css/style.css --watch
   
4. Open with Live Server or manually open index.html in your browser.

##Deployment
This site can be deployed using GitHub Pages, Netlify, or Vercel. The current setup assumes static hosting.
